## Instructions

1. **Download images** from the sources listed above
2. **Save each image** to: `public/images/products/`
3. **Use the exact filename** specified in the checklist
4. **Recommended format:** JPG for photos, PNG for graphics with transparency
5. **Recommended size:** 1200x800px or larger (minimum 800x600px)
6. **File size:** Keep under 500KB per image for web performance

## After Downloading

Once all images are downloaded and saved to `public/images/products/`, run the update script:

```bash
node scripts/update_product_images.js
```

This will automatically update `src/lib/products.ts` to replace SVG paths with the new JPG paths.
